🔥 Configuración Firebase

Conecta la app a tu proyecto de Firestore para guardar datos en la nube

📋 Credenciales del Proyecto Firebase

Ingresa los datos de tu proyecto Firebase. Los encontrarás en Firebase Console → Configuración del proyecto → Tu aplicación web

📟 Consola de Estado
// Consola Firebase – Milenium Producción
// Configura tus credenciales y haz clic en "Guardar y Conectar"
📖 Instrucciones de Configuración
Paso 1: Ve a console.firebase.google.com y crea un nuevo proyecto
Paso 2: En el proyecto, ve a Configuración → Tu aplicación web → Agregar app
Paso 3: Copia las credenciales del objeto firebaseConfig y pégalas arriba
Paso 4: Habilita Firestore Database en el panel de Firebase (modo producción o prueba)
Paso 5: Haz clic en "Guardar y Conectar" y luego "Subir datos locales"

Reglas de Firestore recomendadas (para desarrollo):
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true; // ⚠️ Solo para desarrollo
    }
  }
}
